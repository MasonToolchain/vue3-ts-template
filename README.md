# vue3-ts-template

一个开箱即用的 Vue 3 + TypeScript 初始模板，面向中后台与工程化项目启动场景。  
目标是提供清晰、稳定、可扩展的基础结构，帮助你快速开始业务开发。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- ESLint

## 特性

- 基于 TypeScript 的类型安全开发体验
- 现代化构建与本地开发环境
- 预置路由与状态管理能力
- 统一代码规范，便于团队协作
- 适合作为通用前端项目脚手架

## 快速开始

1. 安装依赖  
   `pnpm install`

2. 启动开发环境  
   `pnpm dev`

3. 构建生产版本  
   `pnpm build`

## 常用命令

- `pnpm dev` 启动开发服务器
- `pnpm build` 构建生产版本
- `pnpm preview` 本地预览构建结果
- `pnpm lint` 代码检查

## 目录建议

- `src/` 业务源码
- `src/router/` 路由配置
- `src/stores/` Pinia 状态管理
- `src/components/` 通用组件
- `public/` 静态资源
